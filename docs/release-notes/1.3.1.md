A maintenance release. cafesf2 converts every sound archive and every JAudio game to the same files as 1.3.0.

## Downloads

| File | Contents |
|---|---|
| `cafesf2-1.3.1-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bfsar`, `.baa` or `.aaf` files onto `cafesf2.exe`. You can also use a terminal. `cafesf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Cafesf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **Paths outside the code page on Windows.** cafesf2 now runs with UTF-8 as its code page. An archive or a folder whose name the system's code page can't hold, such as a Japanese name on an English system, now opens.
- **The libraries.** cafesf2 now builds on ntdlib 3.6.0 and xsflib 1.10.0, with seqlib 1.4.0.

## Known limitations

As in 1.3.0. See "JAudio games", "SFZ files" and "Differences from the game" in the README for the full list.
