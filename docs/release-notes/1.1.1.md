A release with three fixes to the conversion of JAudio games. They change some of Twilight Princess HD's sound effects. Sound archives and The Wind Waker HD convert as in 1.1.0.

## Downloads

| File | Contents |
|---|---|
| `cafesf2-1.1.1-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bfsar`, `.baa` or `.aaf` files onto `cafesf2.exe`. You can also use a terminal. `cafesf2 --help` lists the options. Output goes in a folder beside each input.

For macOS on Apple Silicon, follow the build instructions in the README. macOS builds include `Cafesf2.app`. Drop archives onto the app in Finder to convert them.

## Fixes

- **A jump to the next command.** cafesf2 counted a jump to the command right after it as a jump back. The loop markers of a sequence with such a jump could then go in the wrong place. The game's player just moves on at such a jump. cafesf2 now does the same.
- **Envelope scaling.** JAudio's command 0xe7 scales a track's envelope. cafesf2 ignored it. The tracks that use it now play at the game's level. Their notes also end where the game ends them.
- **The DSP's pitch limit.** The game holds a voice's pitch at the DSP's limit. Notes above the limit now play at the limit in the SoundFonts and SFZ files too.
- **Notes past the limit of one tick.** The README said that the Wii U keeps the newest 96 notes when a track starts more than 96 in one tick. The Wii U keeps the first 96. cafesf2's `--voices` already did. The README and the report of those notes now say so.

## Other changes

- **The README.** A SoundFont sample's unrolled loop is followed by 32 samples, not 8 as the README said. The account of the main loop now describes inner loops. It also says that a tie or mono legato on a note below hearing changes nothing that can be heard. The build section shows how to clone the libraries. The test section lists the other checks and tools.
- **The libraries.** cafesf2 now builds on seqlib 1.2.0, xsflib 1.3.0 and ntdlib 1.8.0.

## Known limitations

As in 1.1.0, apart from the fixes above. See "JAudio games" and "Differences from the game" in the README for the full list.
